## 真实模型证据要求

- 至少覆盖正常路径、超预算重规划、工具失败调整；资料缺口场景也保留输入输出和 Trace。
- 至少两条路径必须体现真实工具结果改变了模型后续动作；离线分支不能替代。
- 评估分别记录任务完成情况、硬约束违规是否被拦截、模型无效动作及调整是否合理。工具拦截成功不自动计作模型决策成功。
- 用固定版本资料和工具表复测；保存原始失败，不能只提交成功重跑。
- 成本算术、依赖、重复执行等由确定性检查核对；脚本是否切题、素材事实支持情况另行审阅。
