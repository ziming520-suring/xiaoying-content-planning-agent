# 第六阶段：受约束生成修复

第五阶段发现来源ID校验无法阻止事实扩写，17份脚本中8份含具体无依据断言；P04无资料仍提交3次无效动作。本版本采用可确定性校验的原句编排，原始失败与基线均保留。

## 行为变化

新生成协议source_sentences_v2仍真实调用qwen-plus。模型根据资料选择、排列完整facts句子，输出固定中性标题“功能介绍”，正文允许原句及中性开场/收尾。程序拒绝新增事实、改写、拼接、无覆盖的来源、重复句子和无依据标题。每份给定素材至少出现一条事实，来源集合精确匹配。

这是一项能力取舍：新结果是模型在线编排资料原句，不是自由创作文案，也不是由离线模板冒充模型输出。适合当前简单合成资料的功能介绍，不代表完整营销活动创意。资料本身若有错误，校验不会判断其现实真实性。

没有任何非空检索结果时，发给模型的工具集合仅包含search_materials与finish。即使模型返回未提供工具，适配器也拒绝，不执行该动作。检索有素材后恢复原有工具集合，预算、截止、依赖与保存校验不变。该措施不解决“检索有结果但语义不相关”，仍须模型判断主题。

供应商若返回句子字符串数组，先用换行连接，再进行完全相同的逐句校验，不修补或删除其中的事实。已收到的模型决策若JSON无效或工具不可用，记录invalid_model_output拒绝事件并占用一个动作，再向下一次模型决策提供格式纠错观察；达到max_actions仍停止。网络、usage或未知调用错误不进入这一纠错分支，仍保留预留并停止。

## 兼容与恢复

新远程生成journal的payload保存generation_protocol。旧journal没有该字段时，按原有generate_script_legacy的完全相同提示词和协议恢复已发调用，避免变更请求指纹后误判冲突或重复发送。旧版恢复的脚本没有content_policy=source_sentences_v2，不能声称经过新校验；旧版已完成任务和脚本也不会被偷偷改写。

新任务采用新协议；复用历史结果或恢复历史任务时应检查每份脚本来源和content_policy。旧协议兼容不代表旧质量问题被回溯修复。旧版有确定回执而无本地结算的恢复测试确认只发送一次。

## 验证与发布

免费测试覆盖上线、具体样式/语言承诺、标题扩写、正文空事实、来源重复、无素材工具限制及旧缓存兼容。历史业务/事务回归继续保留。真实比较使用与第五阶段完全相同的两轮7场景和4种扰动，共18任务；最终数字见第六阶段评估报告。

第五阶段的历史聚合脚本需要在第五阶段ZIP中运行，因为它明确要求当时业务源码不变；当前版本已修复，不能冒称仍与旧源码一致。原始JSON/Trace没有修改。
